programming language

Java is a popular, object-oriented programming language used to develop web applications, mobile applications, desktop software, and enterprise applications.
python
Python is a simple and easy-to-learn, high-level programming language used for web development, data analysis, AI, machine learning, and automation.
C
C is a general-purpose programming language commonly used for system programming, operating systems, embedded systems, and software development.
C++
C++ is an object-oriented programming language based on C. It is used for game development, system software, desktop applications, and high-performance programs.

jQuery is a JavaScript library that makes it easier to write JavaScript code. It is commonly used for DOM manipulation, events, animations, and AJAX.
